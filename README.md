# The Reading Room

CAT VARC reading sprint dashboard for 16–28 November 2026.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Choose branch `main` and folder `/(root)`, then Save.
4. After deployment, visit https://jayamishra2520-a11y.github.io/the-reading-room/ .

Reading progress and reflections are stored locally in your browser. Reading cards currently open each publisher's long-form library, where you can select an appropriate full-length essay. This first build establishes the full 13-day experience; article-specific links and bespoke analysis are the next content pass.
